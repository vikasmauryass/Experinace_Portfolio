# Vikas Maurya – Portfolio (Next.js)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
- Edit all content in `data/portfolio.js`.
- Change `site.url` to your real domain (SEO, sitemap, Open Graph).
- Add `app/opengraph-image.png` (1200x630) for link previews.
- Deploy: push to GitHub and import in Vercel, or Netlify (Next.js runtime).
